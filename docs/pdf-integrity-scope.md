# PDF 파일 무결성 검증

- 결정일·구현일: 2026-11-02
- 범위: PDF 전자 파일 자체. 종이 출력물의 진위·OCR·QR 검증은 제외한다.

## 사용 방법

1. 관리자 모드에서 세무 리포트 → 운행기록부 PDF를 연다.
2. 타임스탬프 전송이 켜져 있으면 FreeTSA 문서 타임스탬프를 발급하고 PDF 안에 넣는다. PDF 원문 대신 SHA-256 지문만 전송한다.
3. 미리보기의 **PDF 증명 확인**으로 확인 후 PDF를 저장한다. **원장 JSON 저장**은 기존 원장 데이터를 위한 별도 기능이며 PDF 검증에 필수인 파일은 아니다.
4. 기존 파일은 세무 리포트의 **PDF 파일 검사**로 선택한다. 파일 선택기에서 돌아오면 관리자가 잠기므로 잠금 해제 후 검사 버튼을 다시 누른다. 최대 32MB까지 앱 내부에서 읽어 검사하며 파일을 서버로 업로드하지 않는다.
5. 발급 실패·전송 꺼짐은 **증명 없음**으로 표시하고 `_미증명.pdf`로 저장한다. 전송을 켠 상태에서 미리보기의 재시도로 증명을 발급할 수 있다. 미증명 PDF를 다시 내보내는 것만으로 과거 생성 시점이 증명되지는 않는다.

## 보호 대상과 판정

- PDFBox Android로 `/DocTimeStamp`, `/SubFilter /ETSI.RFC3161`을 추가한다.
- `/ByteRange`는 토큰을 넣는 Contents 영역 이외의 전체 파일 바이트를 덮어야 한다. 제외 구간이 Contents의 16진수와 정확히 일치하는지도 확인한다.
- 지문·토큰 서명·서명 시점 인증서 유효성·공식 FreeTSA 루트까지의 PKIX 인증서 경로를 검증한다. 토큰에 들어 있는 루트를 그대로 신뢰하지 않는다.
- 저장 후 서명 범위 수정·주석·페이지 추가·추가 저장은 파일 변경 없음으로 통과시키지 않는다.
- 결과는 **파일 변경 없음 / 증명 없음 / 검증 실패 / 기관 확인 불가**로 구분한다. 증명이 없거나 다른 기관의 서명이라는 이유만으로 변조를 확정하지 않는다.
- 일일 원장 타임스탬프와 PDF 타임스탬프는 별개다. 기존 원장 해시체인·앵커·JSON은 유지한다.

## 공식 인증서

- 출처: https://www.freetsa.org/files/cacert.pem
- 공식 안내: https://www.freetsa.org/index_en.php
- 배포 파일: `app/src/main/assets/tsa/freetsa-root.pem`
- PEM 파일 SHA-256: `2151b61137ffa86bf664691ba67e7da0b19f98c758e3d228d5d8ebf27e044438` (공식 안내의 값과 대조)
- 루트 유효기간: 2016-03-13 ~ 2041-03-07. 교체 시 과거 검증에 필요한 루트를 폐기하지 않는 정책을 별도로 마련해야 한다.

## 한계

- 새 PDF의 증명 기관은 FreeTSA 하나다. 일일 원장은 기존처럼 FreeTSA 실패 시 Sectigo를 사용한다. PDF에서 FreeTSA 실패는 숨기지 않고 미증명으로 처리한다.
- 인증서 폐기 상태(OCSP/CRL) 및 장기 검증 증거 보관은 미지원이다. 검증 결과에도 명시한다. 외부 뷰어는 FreeTSA 루트를 기본 신뢰하지 않을 수 있으므로 공식 인증서 설정이 필요할 수 있다.
- 한 개의 ETSI.RFC3161 문서 타임스탬프를 지원한다. 타 기관 인증서·복수 서명·일반 전자서명은 기관 확인 불가로 처리한다.
- 실제 운행 사실·업무 목적의 진실성·발급자 신원·종이 사본은 증명하지 않는다.
- PDF 발급 시 기관 시각과 실제 기기 시각 차이가 5분을 넘으면 발급을 완료 처리하지 않는다. 차량 시연용 가상 시각은 이 검사에 사용하지 않는다.

## 확인 상태

데모·실제 모드 Kotlin 컴파일과 APK 조립을 확인했다. 사용자 지침에 따라 테스트를 추가하거나 실행하지 않았다. 실제 FreeTSA 발급·PDF 변경 시나리오·외부 PDF 뷰어 및 실기기 실행은 미확인이다.
