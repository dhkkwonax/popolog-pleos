# 로컬 관리자 사용 및 확인 기록

- 구현·확인일: 2026-11-01
- 기획: [설계 변경 이력](../../popolog-team/ADMIN_AUTH_DESIGN_CHANGE.md)
- OpenSpec: `add-local-admin-pin`

## 사용 방법

1. 정차 중 설정 맨 위의 **차량 관리자 → 관리자 PIN 설정**에서 숫자 6자리를 두 번 입력한다. 설정을 건너뛰어도 기본 기록·차량 요약·비용 추가를 사용할 수 있다.
2. 한 번 표시되는 복구 코드를 차량 밖에 별도 보관한다. 복구 코드 화면에는 Android 캡처 방지를 적용했다. 설정 직후에는 잠겨 있으므로 PIN으로 관리자를 연다.
3. 관리자 모드에서는 장부·과거 운행·원장·세무 자료를 조회하고 PDF·CSV·검증 JSON을 저장·공유한다. 잠겨 있으면 해당 화면 대신 인증 안내를 표시한다.
4. **관리 종료**, 다른 앱으로 이동, 앱 재실행 또는 주행 시작 시 다시 잠긴다. 보호 대화상자도 닫는다. 기본 자동 기록은 계속한다.
5. **PIN 변경·관리자 인계**는 현재 PIN 재확인 후 새 PIN을 두 번 입력한다. 새 복구 코드를 보관한다. **PIN을 잊었어요**에서는 기존 복구 코드와 새 PIN으로 기록을 보존한 채 재설정한다.
6. 매각 삭제는 관리자 PIN 재확인 후 기존 안내·정확한 `삭제` 입력을 거친다. 이미 승인된 삭제 작업은 중단 후 재시도할 수 있다. 실제 삭제 완료 단계에서 관리자 정보도 제거한다.

일반 운전자는 홈에서 이번 실행 중 마지막으로 완료한 운행의 목적·이용자를 확인할 수 있다. 새 운행이 시작되면 이전 운행 질문은 제거한다. 과거 기록을 고치려면 관리자 권한이 필요하다. PIN·복구 코드 5회 연속 오류부터 대기 시간을 적용하며 최대 960초까지 늘어난다. 실패 횟수와 대기 상태는 재실행해도 유지한다.

## 저장·보호 범위

- 자격 검증값은 `local_admin` SharedPreferences에 저장한다. 업무 SQLite DB와 일반 기록 스냅샷에 넣지 않는다. 원문 대신 PBKDF2-HMAC-SHA256 210,000회·난수 salt 및 Android Keystore HMAC 키를 사용한다.
- 복구 코드는 난수 128비트이며 원문을 앱에 저장하지 않는다. 인증 결과는 활성 화면에서만 메모리 세션으로 전환한다. 백그라운드에서 끝난 인증이나 닫힌 창의 결과로 잠금을 해제하지 않는다.
- PIN은 이 차량 앱의 관리 기능 잠금이다. 실명·재직·차량 소유권 인증이 아니다. 최초 설정은 차량 소유자·회사 담당자가 직접 수행한다.
- 앱 제거·데이터 초기화·루팅·이미 내보낸 문서(PDF·CSV·검증 JSON은 암호화하지 않는다)까지 보호하지 않는다. 앱 DB는 Android Keystore가 보호하는 키로, 공용 백업은 PIN·복구 코드로 암호화하지만(`record-backup.md`), 6자리 PIN은 백업 파일을 확보한 사람의 오프라인 대입까지 막지는 못한다. PIN과 복구 코드를 모두 잃으면 기록을 유지한 채 인증을 건너뛰는 초기화를 제공하지 않는다.
- 보존기간 기산점·기간 변경 화면·만료 삭제 엔진은 이번 구현 범위가 아니다. 백업 형식·자동 갱신 주기·재설치 복구·매각 삭제 통합 확인은 기존 보류 상태를 유지한다. 기존 복구 실행에도 관리자 인증이 필요하며, 폴더 선택 후에는 다시 잠금을 해제하고 **선택한 폴더의 복구 파일 보기**로 계속한다.

## 확인 환경과 범위

- JDK 17, Android SDK 34, Gradle `assembleDemoDebug`와 `compileRealDebugKotlin` 성공.
- Pleos 에뮬레이터 `emulator-5570`, 사용자 10, 2560×1440. `ai.chagok.adminpreview` 별도 패키지로 설치해 기존 `ai.chagok.app` 데이터를 보존했다.
- PIN 설정·복구 코드 표시·오입력 거부·정상 인증·인증 전후 운행/세무 접근·관리 종료·앱 복귀 잠금을 실제 UI로 확인했다.
- 잠긴 상태에서 `QUERY_REPORT`의 `export_pdf` 외부 Intent를 보내 PDF 미리보기를 열지 못하는 것을 확인했다.
- 관리자 인계 진입 시 기존 PIN 재확인을 요구하고 새 PIN 단계로 진행하는 것을 확인한 뒤 취소했다. 최종 APK에서는 정상 인증과 복구 코드 기반 PIN 재설정·복구 코드 교체를 실제 UI로 확인했다.
- 별도 코드 리뷰에서 홈의 과거 기록·데모 초기화 우회, 현재 운행 이용자 확인 진입점과 오래된 질문 노출을 보완했다. 비용 수정·삭제·내보내기는 실행 시 권한을 다시 확인한다.
- 사용자 지침에 따라 테스트를 추가·실행하지 않았다. 이 기록의 에뮬레이터 조작은 요청한 기능 화면 확인·촬영이다. 실차 신호, 5회 오입력 후 재부팅 대기, 실제 매각 삭제와 백업 복구 통합은 수행하지 않았다.

## 스크린샷

원본은 [관리자 촬영 폴더](../screenshots/admin-20261101/)에 있다. 2026-11-01 사용자 지시에 따라 **Popolog 하나가 2col을 쓰는 배치**와 **Popolog 1col + 내비게이션 1col 배치**로 다시 촬영했다. 두 Popolog 시연 앱을 나란히 띄운 기존 이미지는 제출용 폴더에서 제외했다. PIN·복구 코드 원문은 이미지에 노출하지 않는다.

내비게이션 지도 타일은 현재 에뮬레이터에서 표시되지 않는다. 빈 지도 화면을 그대로 촬영했으며 지도나 경로를 합성하지 않았다. 창 배치 확인과 실차 내비게이션 동작 확인은 구분한다.

과거 촬영에서 확인한 기능 동작 기록은 위 확인 범위에 유지한다. 과거 이미지의 개발용 이중 앱 배치는 제품의 사용 시나리오로 제시하지 않는다.

## APK

- `app-studio/apk/Popolog-demo-admin-20261101.apk`: 기본 패키지의 데모 빌드. 기존 앱에는 설치하지 않았다.
- `app-studio/apk/Popolog-admin-preview-20261101.apk`: 별도 촬영용 패키지. 기존 사용자 기록과 분리되어 있다.
- 촬영용 앱 PIN은 `482963`이다. 기존 실제 설치 앱에는 PIN을 설정하거나 데이터를 변경하지 않았다.
- 별도 패키지 빌드 옵션: `-PpreviewApplicationId=ai.chagok.adminpreview`. 옵션이 없으면 기존 패키지 `ai.chagok.app`을 유지한다.
