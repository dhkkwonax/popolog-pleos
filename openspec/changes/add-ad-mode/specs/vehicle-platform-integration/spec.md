# Spec Delta

## ADDED Requirements

### Requirement: 차속을 공통 인터페이스로 전달하고 사용 불가를 구분한다

**MUST:** 시스템은 차속(km/h)을 공통 차량 인터페이스로 전달해야 한다. 실제 동작 모드는 CarPropertyManager `PERF_VEHICLE_SPEED`를 읽으려 시도하고, 권한 거부·미지원 등으로 읽을 수 없으면 "측정 불가"를 전달해야 하며 다른 차량 신호 처리에 영향을 주어서는 안 된다. 데모 모드는 가상 주행 중 60, 정차 0을 전달한다.

#### Scenario: 차속 수신

- **WHEN** 차량이 차속을 제공한다
- **THEN** 앱은 최신 차속과 수신 시각을 광고 모드 정책에 전달한다

#### Scenario: 차속 읽기 실패

- **WHEN** 차속 속성 접근이 거부되거나 지원되지 않는다
- **THEN** 앱은 측정 불가를 전달하고 운행 기록 등 기존 기능은 계속 동작한다
