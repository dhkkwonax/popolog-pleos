# Spec Delta

## ADDED Requirements

### Requirement: 동의를 먼저 받고, 동의하면 광고 모드가 기본 켜짐이다

**MUST:** 사용자가 동의하기 전에는 광고 모드가 꺼져 있어야 한다. 앱은 동의 여부를 아직 고르지 않은 상태에서 처음 열릴 때(실제 모드는 개인정보 처리 안내를 확인한 뒤) 위치·광고 동의 안내와 아래 위험 안내를 보여 주고, 사용자가 "동의하고 켜기"를 고른 경우에만 동의로 기록하고 광고 모드와 소리 광고를 기본 켜짐으로 시작해야 한다. "동의 안 함"을 고르면 꺼진 채로 두고 다시 묻지 않으며, 설정에서 언제든 다시 켤 수 있다. 광고는 광고임을 고지해야 한다. 사용자에게 어떤 것도 강제하지 않으며, 켜기·끄기·소리 광고 사용 여부는 모두 사용자가 직접 선택한다.

#### Scenario: 처음 열기

- **WHEN** 동의 여부를 고른 적 없는 상태로 앱이 열린다
- **THEN** 시스템은 동의 안내를 표시하고, "동의하고 켜기"를 누르면 동의를 기록하고 광고 모드와 소리 광고를 켠다

#### Scenario: 동의 안 함

- **WHEN** 사용자가 "동의 안 함"을 고른다
- **THEN** 시스템은 광고 모드를 끈 채로 두고 다시 묻지 않는다

#### Scenario: 주행 중 설정 변경

- **WHEN** 사용자가 주행 중에 설정을 변경한다
- **THEN** 시스템은 막지 않고 선택대로 반영한다

### Requirement: 사용자가 선택할 때 생길 수 있는 문제를 미리 알린다

**MUST:** 광고 모드 설정 카드와 동의 화면은 "켜기 전에 알아두세요"로 다음을 알려야 한다: 주행 중 화면 조작·광고 시청은 주의 분산으로 위험할 수 있음, 주행 중 광고 표시와 터치 조작은 차량 플랫폼의 운전 중 조작 제한 정책이나 앱 마켓 심사 기준에 어긋나 배포가 거절될 수 있음, 소리 광고는 기본 켜짐·횟수 제한 없음이라 정차할 때마다 반복되어 번거롭고 대화·내비 안내와 겹치거나 음성 인식이 잘못 반응할 수 있음(원치 않으면 끌 수 있음), 위치는 광고 선택에만 쓰고 운행기록·세무 자료에 저장하지 않음, 데모 광고는 예시이며 실제 매장 정보와 다를 수 있음.

#### Scenario: 안내 표시

- **WHEN** 사용자가 광고 모드 설정을 보거나 처음 켠다
- **THEN** 시스템은 위 위험 안내를 함께 표시한다

### Requirement: 출발하면 전체 화면 광고 이미지 1장을 고정한다

**MUST:** 광고 모드가 켜져 있고 차속이 0보다 크면 앱 전체 화면을 광고 정지 이미지 1장으로 바꿔야 한다. 주행 중에는 이미지·레이아웃을 바꾸지 않으며 애니메이션·영상·깜빡임을 사용하지 않는다. 화면 우상단에 "광고" 라벨을, 좌상단에 "이 광고는 Popolog를 통해 제공됩니다" 문구를 상시 표시해야 한다. 데모 광고 소재는 현대자동차·기아 매장이 근처에 있다고 가정한 문구로 하며 브랜드 로고·외부 사진은 쓰지 않는다. 소리 광고도 "Popolog가 전하는 광고입니다"로 시작해야 한다.

#### Scenario: 출발

- **WHEN** 광고 모드가 켜진 상태에서 차속이 0보다 커진다
- **THEN** 시스템은 광고 이미지를 한 번 표시하고 이후 주행 중 유지한다

#### Scenario: 주행 중 변화 없음

- **WHEN** 광고 화면 표시 중 차가 계속 주행한다
- **THEN** 시스템은 이미지를 교체하지 않는다

### Requirement: 광고 화면에서 버튼으로 앱 화면에 갈 수 있다

**MUST:** 광고 화면은 자동으로 일반 화면으로 돌아가지 않아야 한다. 대신 화면 하단에 "앱 화면으로" 버튼을 항상 표시하고, 사용자가 원하면 정차 여부와 상관없이 그 버튼을 눌러 앱 화면으로 갈 수 있어야 한다. 복귀하면 다음 광고 이미지로 교체하고, 같은 주행 중에는 광고를 다시 표시하지 않으며 차속 0이 한 번 확인된 뒤 다시 출발할 때부터 표시한다.

#### Scenario: 주행 중 버튼

- **WHEN** 광고 화면 표시 중 사용자가 "앱 화면으로" 버튼을 누른다
- **THEN** 시스템은 앱 화면(기록 화면)으로 복귀하고 다음 이미지를 준비하며, 주행이 이어져도 광고를 다시 띄우지 않는다

#### Scenario: 정차 중 버튼

- **WHEN** 정차 중에 사용자가 버튼을 누르지 않는다
- **THEN** 시스템은 광고 화면을 그대로 유지한다

#### Scenario: 정차 뒤 재출발

- **WHEN** 버튼으로 복귀한 뒤 차속 0이 확인되고 다시 출발한다
- **THEN** 시스템은 다음 광고 이미지를 표시한다

### Requirement: 차속을 알 수 없으면 광고를 띄우지 않는다

**MUST:** 차속이 없거나 5초 넘게 갱신되지 않으면 광고 화면을 표시하지 않고 일반 화면을 유지해야 한다.

#### Scenario: 차속 사용 불가

- **WHEN** 차속 신호를 읽을 수 없다
- **THEN** 시스템은 광고 화면으로 전환하지 않는다

### Requirement: 소리 광고는 기본 켜짐이고 횟수 제한이 없으며 사용자가 끌 수 있고 정차 시점에만 제안한다

**MUST:** 소리 광고는 광고 모드가 켜져 있을 때 기본 켜짐으로 제안하되 사용자가 설정에서 언제든 끌 수 있어야 한다. 하루 횟수 제한은 두지 않으며, 정차 중(일반 화면)에만 제안해야 한다. 제안은 광고임을 밝히고 사용자 응답 없이 경로·경유지를 바꾸지 않는다.

#### Scenario: 횟수 제한 없음

- **WHEN** 정차할 때마다 소리 광고 제안 조건이 충족된다
- **THEN** 시스템은 횟수와 상관없이 제안한다

#### Scenario: 사용자가 끔

- **WHEN** 사용자가 소리 광고를 끈다
- **THEN** 시스템은 소리 광고를 제안하지 않는다

#### Scenario: 주행 중

- **WHEN** 광고 화면 표시 중이다
- **THEN** 시스템은 소리 광고를 재생하지 않는다

### Requirement: 사용자가 즉시 해제할 수 있다

**MUST:** 음성 "광고 그만" 또는 설정 OFF로 광고 모드를 끌 수 있어야 하며 해제 즉시 일반 화면을 유지해야 한다. 광고 모드가 꺼져 있으면 주행 중 화면은 기존 최소 상태 표시를 유지한다.

#### Scenario: 음성 해제

- **WHEN** 사용자가 "광고 그만"이라고 말한다
- **THEN** 시스템은 광고 모드를 끄고 일반 화면을 표시한다

### Requirement: 광고는 운행 기록·해시체인·세무 산출물과 분리한다

**MUST:** 광고 노출·동의·소리 횟수는 운행, 비용, 원장 해시체인, 앵커, 세무 PDF, 운행기록 CSV에 기록하거나 표시하지 않아야 한다.

#### Scenario: 세무 리포트

- **WHEN** 광고가 노출된 날의 세무 리포트를 생성한다
- **THEN** 리포트와 원장에는 광고 항목이 없다
