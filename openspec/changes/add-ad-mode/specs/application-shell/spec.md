# Spec Delta

## ADDED Requirements

### Requirement: 광고 모드 화면은 일반 화면 위에서 전체 화면으로 표시한다

**MUST:** 광고 상태에서 앱은 탐색 레일을 포함한 전체 화면을 광고 이미지로 덮고, 우상단 "광고" 라벨과 하단에 주행 중에는 안내 문구를, 정차가 이어지면 "기록 화면으로" 버튼을 표시해야 한다. 일반 화면의 데이터와 탭 상태는 복귀 후 유지해야 한다.

#### Scenario: 버튼 복귀

- **WHEN** 운전자가 "기록 화면으로" 버튼을 눌러 광고 상태가 종료된다
- **THEN** 앱은 직전에 보던 탭의 일반 화면을 다시 표시한다

### Requirement: 설정에서 광고 모드를 관리한다

**MUST:** 설정 화면은 광고 모드 켜기/끄기, 동의 안내, 소리 광고 한도 안내를 제공해야 한다. 데모 flavor는 광고 화면 시연을 위한 가상 출발·정차 조작을 제공할 수 있다.

#### Scenario: 설정 OFF

- **WHEN** 사용자가 정차 중 설정에서 광고 모드를 끈다
- **THEN** 이후 출발해도 광고 화면으로 전환하지 않는다
